API Documentation

Use the Student REST API and Mock Interview API for integrations.

  • GET /api/students/ - list students
  • POST /api/students/ - create student
  • GET /api/students/{id}/ - student detail
  • PUT /api/students/{id}/ - update student
  • DELETE /api/students/{id}/ - delete student
  • GET /api/students/questions/ - list interview questions
  • POST /api/students/questions/ - add question
  • GET /api/students/questions/{id}/ - question detail
  • PUT /api/students/questions/{id}/ - update question
  • DELETE /api/students/questions/{id}/ - delete question
  • GET /api/students/sessions/ - list sessions
  • GET /api/students/sessions/{id}/ - session detail with messages

Mock interview widget endpoint:

/students/mock-interview/api/

Then use JSON body: {"question": "...", "session_id": optional, "question_id": optional}.
